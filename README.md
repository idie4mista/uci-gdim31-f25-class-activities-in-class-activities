the R. G, and B values are stored as floats these values are stored as a decimal, from 0.1 to 1.0, unlike the standard -255 to 255 for rgb. 
the _bounce variable is stored as an int because it is a whole number. This variable counts how many times the ball has bounced from a surface and therefore doesn't need to be a fractional number.
